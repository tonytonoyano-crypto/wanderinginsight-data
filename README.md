# WanderingInsight data

The code and results behind [WanderingInsight](https://www.youtube.com/@WanderingInsight) videos. *Answers to questions you didn't ask.*

Every episode we compute our own maps and charts from public data. This repo is where you can check our work, change the rules, and see what moves.

| Episode | Question |
|---|---|
| [ep01-farthest-from-ocean](ep01-farthest-from-ocean/) | Where is the farthest place on land from any ocean? |

## Setup

```bash
pip install -r requirements.txt
```

Each episode folder has its own README with the rules, the numbers used in the video, and the commands to run.
